# ملتقى تقييم الطلاب

تطبيق بسيط لتقييم الطلاب، يُثبَّت على الهاتف ويعمل بدون إنترنت.

## ثلاث شاشات فقط

- **الرئيسية**: بطاقة «حماس» (نجوم اليوم، المتصدر، الحضور)، وبطاقات الطلاب بصورهم ونجومهم.
  - اضغطي على الطالب لتقييمه: + و − لكل معيار، والحضور (حاضر / غائب / متأخر).
  - زر «الكل حاضر»، وزر ➕ لإضافة طلاب أو مجموعات مباشرة.
  - زر «تراجع» بعد كل تقييم.
  - زر 🎡 **عجلة المشاركة**: تدور وتختار طالباً. «شارك» تضيف +1 في المشاركة وتُخرجه من العجلة لبقية اليوم، و«لم يشارك» تبقيه فيها. الغائبون اليوم لا يظهرون في العجلة.
  - زر «الطلاب / المجموعات» أعلى الشاشة: في عرض المجموعات، تقييم المجموعة يضيف النقطة لكل أعضائها الحاضرين.
- **النتائج**: يومي / أسبوعي / شهري، مع التنقل بين الفترات السابقة، ولوحة صدارة فيها 3 فائزين (🥇🥈🥉) للطلاب وللمجموعات، وجدول لكل معيار، والطباعة والمشاركة.
- **المجموعات** (من الإعدادات): اسم ورمز ولون لكل مجموعة، واختيار طلابها، أو إنشاء مجموعات وتوزيع الطلاب تلقائياً.
- **الإعدادات**: فترة التقييم، تفعيل المعايير أو إضافة معايير جديدة، الطلاب وصورهم، الصفوف، النسخ الاحتياطي.

## الملفات (ارفعيها كلها معاً)

- `index.html` — التطبيق نفسه
- `manifest.webmanifest` — اسم التطبيق وأيقونته
- `sw.js` — يجعل التطبيق يعمل بدون إنترنت
- `icon-192.png` و `icon-512.png` — أيقونة التطبيق

## رفعه على GitHub Pages (مرة واحدة)

1. أنشئي حساباً مجانياً على github.com إن لم يكن لديك.
2. اضغطي **+** ثم **New repository**، واكتبي اسماً مثل `multaqa`، واختاري **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغطي **uploading an existing file** (أو **Add file ← Upload files**)، واختاري الملفات الخمسة، ثم **Commit changes**.
4. افتحي **Settings ← Pages**، وتحت **Branch** اختاري `main` ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط بالشكل:
   `https://اسم-حسابك.github.io/multaqa/`

هذا الرابط هو ما ترسلينه لأي شخص ليثبّت التطبيق.

## التحديث لاحقاً

ارفعي الملف الجديد مكان القديم بنفس الطريقة، وغيّري رقم النسخة في أول سطر من `sw.js`
(مثلاً من `multaqa-v5` إلى `multaqa-v6`). يصل التحديث لكل من ثبّت التطبيق عند فتحه وهو متصل.

## البيانات

كل شخص بياناته في جهازه فقط. لنقل البيانات بين جهازين:
**الإعدادات ← النسخ الاحتياطي ← تصدير**، ثم على الجهاز الآخر **استيراد**.

عند فتح هذا الإصدار أول مرة تُنقل الصفوف وأسماء الطلاب من الإصدار السابق تلقائياً.

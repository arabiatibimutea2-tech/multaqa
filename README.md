# ملتقى تقييم السلوك والمشاركة

تطبيق لتقييم سلوك ومشاركة الطلاب، يُثبَّت على الهاتف ويعمل بدون إنترنت.

## الملفات (ارفعيها كلها معاً)

- `index.html` — التطبيق نفسه
- `manifest.webmanifest` — اسم التطبيق وأيقونته
- `sw.js` — يجعل التطبيق يعمل بدون إنترنت
- `icon-192.png` و `icon-512.png` — أيقونة التطبيق

## رفعه على GitHub Pages (مرة واحدة)

1. أنشئي حساباً مجانياً على github.com إن لم يكن لديك.
2. اضغطي **+** ثم **New repository**، واكتبي اسماً مثل `multaqa`، واختاري **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغطي **uploading an existing file** (أو **Add file ← Upload files**)، واختاري الملفات الخمسة، ثم **Commit changes**.
4. افتحي **Settings ← Pages**، وتحت **Branch** اختاري `main` ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط بالشكل:
   `https://اسم-حسابك.github.io/multaqa/`

هذا الرابط هو ما ترسلينه لأي شخص ليثبّت التطبيق.

## التحديث لاحقاً

ارفعي الملف الجديد مكان القديم بنفس الطريقة، وغيّري رقم النسخة في أول سطر من `sw.js`
(مثلاً من `multaqa-v1` إلى `multaqa-v2`). يصل التحديث لكل من ثبّت التطبيق عند فتحه وهو متصل.

## البيانات

كل شخص بياناته في جهازه فقط. لنقل البيانات بين جهازين:
**إدارة الصف ← تصدير البيانات ← نسخ النص**، ثم على الجهاز الآخر **استيراد بيانات** ولصق النص.
